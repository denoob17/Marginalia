How This Project Came Together

  1. We agreed on a theme — a shared "book excerpt" journal — before writing any code.
  2. We built one shared stylesheet so every page would feel consistent.
  3. We tested every link and image path before calling a page finished.
  4. In Assignment #3 we made the site responsive with media queries and Bootstrap.
